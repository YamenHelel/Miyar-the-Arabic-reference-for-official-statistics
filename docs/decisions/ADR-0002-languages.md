# ADR-0002: Languages

- **Date:** 2026-11-03 · **Status:** accepted

## Decision
- Internal project docs (PRD, logs, schemas, code) are in **English**. This is easier for tools, partners and contributors.
- User-facing content (indicator pages, glossary, website UI) is in **Arabic**.
- Official definitions are quoted in their **original language** (EN/FR/AR). Arabic renderings that the publisher did not issue are labelled `translation: unofficial`.
- Arabic term variants by country or region (Maghreb, Mashreq, Gulf) are recorded explicitly; see the data model.

## Consequences
French-language sources (INS Tunisia, HCP Morocco, INSEE) are quoted in French with an Arabic rendering. English and French UI may follow later (I-020).
