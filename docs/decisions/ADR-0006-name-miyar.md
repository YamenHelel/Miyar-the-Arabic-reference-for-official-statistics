# ADR-0006: Project name, Miʿyar (مِعيار)

- **Date:** 2026-11-04 · **Status:** accepted

## Decision
The project is named **مِعيار — المرجع العربي للإحصاء الرسمي** (*Miʿyar: the Arabic reference for official statistics*).

## Why
- "Miʿyar" means *standard / benchmark*. That matches the project's core: international standards (ICLS, SDGs) and how countries apply them.
- It is short, Arabic and serious, and it works for every statistics domain, not only labour.
- The subtitle makes the ambition explicit: *the* Arabic reference for official statistics.

## Conventions
- Arabic: مِعيار (with kasra in titles; plain معيار is acceptable in running text).
- Latin: Miʿyar (display), Miyar (URLs, handles, file names).
- GitHub: `YamenHelel/Miyar-the-Arabic-reference-for-official-statistics`.
