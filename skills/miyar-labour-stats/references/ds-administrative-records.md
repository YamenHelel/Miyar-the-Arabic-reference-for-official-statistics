# السجلات الإدارية — Administrative records and registers / Sources administratives et registres

Miʿyar id: `ds-administrative-records` · data source type · status: draft

## Summary — AI-ASSISTED

السجلات الإدارية بيانات تجمعها جهات حكومية لأغراض عملها، لا لأغراض إحصائية: الضمان الاجتماعي، ومكاتب التشغيل، والخدمة المدنية، وتصاريح عمل الوافدين، والضرائب. تعطي أرقاماً شهرية شاملة ورخيصة عن العمل المسجَّل، لكنها تقيس ما يعرّفه القانون لا ما يعرّفه المعيار الإحصائي، فلا تُقارن بين الدول ولا تقيس البطالة بالمفهوم الدولي.

## How it works — AI-ASSISTED

أهم السجلات لإحصاءات العمل في الدول العشر: سجلات التأمينات والضمان الاجتماعي (المشتركون حسب القطاع والأجر)، وسجلات الخدمة المدنية (موظفو الحكومة)، وسجلات مكاتب التشغيل (طالبو العمل المسجلون)، وتصاريح العمل وإقامات الوافدين (مهمة جداً في دول الخليج)، وسجلات الضرائب، وسجلات تفتيش العمل وإصابات العمل.

## Strengths — AI-ASSISTED

- شاملة للفئة التي يغطيها القانون، بلا خطأ معاينة.
- متاحة بسرعة وبدورية شهرية أحياناً، وبتكلفة إحصائية منخفضة.
- تصلح للمناطق الصغيرة وللقطاعات الدقيقة.
- مفيدة جداً للأجور في القطاع المنظم ولإصابات العمل والحماية الاجتماعية.

## Limits — AI-ASSISTED

- تغطي العمل المسجَّل فقط؛ يغيب عنها العمل غير المنظم والعمل لحساب النفس غالباً.
- تعاريفها قانونية وإدارية؛ «طالب العمل المسجل» ليس «المتعطل» بالمفهوم الدولي.
- تتغير مع تغيّر القوانين والإجراءات، فتنقطع السلاسل لأسباب غير إحصائية.
- الوصول إليها يحتاج اتفاقات بين الجهاز الإحصائي والجهات المالكة، مع حماية البيانات الشخصية.

## What it measures for labour statistics — AI-ASSISTED assessment

| Topic | Fit | Note |
|---|---|---|
| Unemployment (ILO definition) | none | طالبو العمل المسجلون مؤشر إداري مختلف؛ لا يُقدَّم على أنه معدل البطالة. |
| Participation / employment-to-population | none | لا تغطي السكان كلهم. |
| Employment by industry, occupation, status | partial | العمالة المسجلة حسب النشاط بدقة عالية، للقطاع المنظم فقط. |
| Informal employment | none | غياب الشخص عن السجل قد يدل على عدم الانتظام، لكنه ليس قياساً. |
| Hours of work, underemployment | none | نادراً. |
| Earnings and labour cost | main | الأجور المصرَّح بها للضمان الاجتماعي، مع حدود سقف الاشتراك. |
| Small areas | main | حسب مكان المنشأة أو مكتب التسجيل. |
| Frequency and timeliness | main | شهرية أو ربع سنوية. |
